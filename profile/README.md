<p>买线路时最常见的对话是「这条线稳不稳」，对方答「很稳」。这种问答没法验收。把「稳」拆成一组带单位和阈值的参数，才有得谈。下面这份说明书按五组参数列，每项给出含义、建议区间和测量方法，可直接拿去对供应商提问。</p>
<h2>一、线路参数：ASN、段龄、归属数量</h2>
<p>先交代读法：四组参数按「改动的代价」排序，线路参数改一次要换供应商，网络参数改一次要换城市或上游，会话参数改一次是提工单，环境参数改一次只是点几下鼠标。所以先读贵的，再读便宜的。</p>
<table><thead><tr><th>参数</th><th>含义</th><th>建议区间</th><th>怎么测</th></tr></thead><tbody><tr><td>ASN 类型</td><td>持有该 IP 段的机构性质</td><td>本地宽带运营商，非云厂商</td><td>RDAP 查 ASN 与组织名</td></tr><tr><td>段龄</td><td>该地址段首次分配至今的时间</td><td>三年以上更稳</td><td>whois 看分配日期</td></tr><tr><td>归属数量</td><td>同一段在上游登记了几家运营商</td><td>2 家（双归属）优于 1 家</td><td>查路由宣告记录</td></tr><tr><td>同段复用度</td><td>该段是否被大量拆分转售</td><td>越低越好</td><td>看段内相邻 IP 的用途一致性</td></tr></tbody></table>
<h3>为什么要看段龄</h3>
<p>新分配的段在各类库里的归属信息往往还没更新完，不同库给出的城市可能不一致。老段的归属数据稳定，做地区一致性时更省事。</p>
<h3>同段复用度怎么看</h3>
<p>抽几个相邻 IP，查它们的 ASN 与用途是否一致。如果同段里既有家宽也有明显的数据中心用途，说明这段被反复转手，隔离性会打折扣。</p>
<h2>二、网络参数：延迟分位、丢包与抖动</h2>
<p>只看平均延迟会误判。平均五十毫秒的线，可能大部分请求三十毫秒、少数请求三秒，体验上就是「偶尔卡一下」。要分别看 p50 和 p95。</p>
<table><thead><tr><th>参数</th><th>含义</th><th>建议区间</th><th>怎么测</th></tr></thead><tbody><tr><td>p50 延迟</td><td>一半请求快于该值</td><td>跨境 120 到 250 毫秒</td><td>连续 200 次请求取分位</td></tr><tr><td>p95 延迟</td><td>百分之九十五请求快于该值</td><td>不超过 p50 的三倍</td><td>同上，重点看长尾</td></tr><tr><td>丢包率</td><td>无响应请求占比</td><td>低于 1%</td><td>ping 与 TCP 握手结合看</td></tr><tr><td>抖动</td><td>相邻请求延迟的波动幅度</td><td>标准差小于 40 毫秒</td><td>用同一脚本连续采样</td></tr></tbody></table>
<h3>长尾比均值重要</h3>
<p>交互场景里，用户记住的是那几次几秒的卡顿。p95 超过 p50 三倍，说明这条线在高峰期有明显拥塞，宁可换城市也别硬撑。</p>
<h3>丢包和抖动的区别</h3>
<p>丢包是请求没了，抖动是时快时慢。丢包会让脚本重试，抖动只会让人烦躁。两者都测，别混为一谈。</p>

<h2>三、会话参数：粘性窗口、并发上限、重连行为</h2>
<p>这三个参数决定「账号在会话中会不会突然换脸」。原生住宅出口的价值很大程度上体现在这里：出口稳定，会话参数才容易调好。</p>
<h3>粘性窗口</h3>
<p>建议设为最长单次会话的一点五倍。日常对话三十分钟起，处理长文档两小时起。参数名常见有 session、sticky、ttl 几种，开通时写进工单。</p>
<h3>并发与重连</h3>
<p>单条家宽出口的并发上限通常不高，建议按每号同时两到三个连接规划。重连策略要明确：是回原 IP 还是重新分配？前者适合登录态，后者适合无状态抓取，别用错。</p>
<h2>四、环境参数：时区、语言、显示三项</h2>
<p>环境参数不花钱，但最容易漏。三项对齐之后，「一号一环境」才算真的成立，否则只是换了个 IP，环境还在原地。</p>
<h3>时区与语言</h3>
<p>时区跟着出口城市走，语言跟着账号资料走。两者有时不完全一致，比如出口在某国但账号资料用英文，这时以资料为准，保持前后一致即可。</p>
<h3>显示与地理位置权限</h3>
<p>分辨率、字体、地理位置权限三处要固定，不要在多次登录之间反复变化。权限建议设为「拒绝」或固定城市，避免每次弹窗差异。</p>
<h2>五、隔离参数：出口与账号的配比</h2>
<p>最关键的隔离参数只有一个比值：出口数除以账号数。比值等于 1 是一号一线，小于 1 就有号在共用。这个数字写在台账第一行，任何时候都能查。</p>
<table><thead><tr><th>配比</th><th>隔离程度</th><th>适用场景</th><th>风险</th></tr></thead><tbody><tr><td>1 比 1</td><td>完全隔离</td><td>常用号、对外演示号</td><td>成本最高</td></tr><tr><td>2 比 3</td><td>部分隔离</td><td>低频号、内部测试</td><td>共用关系需登记</td></tr><tr><td>1 比 3 及以上</td><td>低隔离</td><td>不建议长期使用</td><td>故障半径大，难定位</td></tr></tbody></table>
<h3>配比不够时怎么取舍</h3>
<p>先保强度高的号。按每天在线时长、是否绑支付、是否对外演示三项打分，分高的独占，分低的排队等新线，不要平均分配。</p>
<h3>配比变化要留痕</h3>
<p>任何一次调整都记时间、原因、操作人。三个月后回看，能看出哪次调整之后异常变多，这个规律比任何参数表都有用。</p>
<h3>配比表和台账怎么对上</h3>
<p>配比表只记数字，台账记的是「哪个号在哪条线上」。两边的出口编号必须能互相查找，月底核对一次，数字对不上说明有人私下改过，这类改动往往就是后续异常的源头。</p>
<h2>常见问答</h2>
<h3>原生住宅和普通住宅在参数上有什么区别？</h3>
<p>答：主要体现在 ASN 归属是否为本地运营商、段龄是否足够、同段复用度是否低。三项都要自己查，不能只看标签。</p>
<h3>p95 延迟高但使用没感觉，需要换吗？</h3>
<p>答：如果任务以短对话为主，可以先用着并继续观察；如果涉及长文档或批量请求，p95 高会明显拖慢整体耗时，建议换城市或换线。</p>
<h3>粘性窗口设太长会有什么问题？</h3>
<p>答：会占用该出口的会话资源，多号共用时容易互相排队。按最长会话的一点五倍设，不要一味拉长。</p>
<h3>参数表需要每次采购都重测吗？</h3>
<p>答：需要。同一供应商不同批次的线路质量可能不同，尤其换城市之后。至少重测线路参数与网络参数两组。</p>
